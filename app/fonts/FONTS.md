# Fonts shipped with Neon Bay Cover Studio

## Anton-Regular.ttf

Anton is a bold condensed display face by Vernon Adams, distributed through
the Google Fonts project. It is released under the SIL Open Font License,
version 1.1, which allows the font to be shipped inside this app, used,
modified and redistributed, including in a commercial product, as long as the
font files themselves are not sold on their own. The full license text lives
at https://openfontlicense.org/ and in the upstream repository at
https://github.com/googlefonts/AntonFont (the file was fetched from the
google/fonts repository, ofl/anton/Anton-Regular.ttf).

The app loads this file only from its own app/fonts/ folder. No other font
file is used, and no font from any game is used anywhere in the entry.
